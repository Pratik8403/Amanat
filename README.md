Amanat 🛡️

Emergency Financial Intelligence Protocol
Amanat is a financial visibility protocol designed to help families access critical financial asset information during emergencies.
In many households, the primary earner manages financial accounts across multiple institutions. During medical crises or unexpected events, families often struggle to locate bank accounts, investments, or insurance policies quickly, causing delays in treatment and financial stress.
Amanat addresses this gap by providing a secure financial intelligence layer that enables users to map their financial assets and designate a verified nominee who can access essential information during emergencies.
The system is designed as a B2B infrastructure layer that integrates directly with fintech ecosystems such as Paytm, PhonePe, and other digital financial platforms.

🌟 Key Capabilities
Unified Financial Visibility
A consolidated view of financial assets including bank accounts, investments, and insurance policies across institutions.

Liquidity Intelligence
The system identifies which assets can be converted into cash quickly during emergencies and presents them through a ranked liquidity map.

Secure Nominee Access
Users can designate a trusted nominee who can activate emergency financial visibility when required.

Emergency Protocol Controls
The account holder retains full authority with a real-time revoke mechanism to terminate access instantly if needed.

Financial Continuity Layer
Amanat helps fintech platforms increase user trust while addressing the national challenge of unclaimed financial assets.

🧠 Technology & Architecture
Amanat is designed to operate within India’s digital financial infrastructure.

Consent-Driven Financial Intelligence
Financial data visibility is based on explicit user consent and secure authorization.

Account Aggregator Framework
The protocol is designed to work with India’s Account Aggregator ecosystem, enabling secure access to financial data across banks, mutual funds, and insurance providers.

Investment Data Integration
Integration with registrars such as CAMS and KFintech allows visibility into investment holdings.

AI-Powered Liquidity Insights
AI models analyze structured financial data to generate:
liquidity maps identifying assets accessible within different time windows
plain-language action guidance for nominees
alerts for assets that require claim procedures or additional documentation

🔄 Emergency Access Workflow
1. Secure Enrollment
The user maps financial assets within their fintech application.

2. Nominee Designation
A trusted nominee is designated and verified through identity checks.

3. Consent Authorization
User consent artifacts are securely stored within the financial data-sharing framework.

4. Emergency Activation
During emergencies, the nominee activates the Amanat protocol within the fintech app.

5. Financial Visibility
The system instantly provides a consolidated view of accessible financial assets.

6. Owner Control
The account holder receives a real-time alert and can revoke access instantly if required.
